# UpJava

Evolução prática em Java — um commit por dia, do zero ao Spring Boot.

Repositório de estudos com exercícios organizados por fase, cobrindo desde sintaxe básica até uma API REST completa com Spring Boot.

## Estrutura

```
UpJava/
├── fase-01-fundamentos/
├── fase-02-poo/
├── fase-03-colecoes-streams/
├── fase-04-excecoes-generics-io/
├── fase-05-testes-build/
├── fase-06-persistencia-jdbc/
├── fase-07-spring-core/
├── fase-08-spring-boot-api/
├── fase-09-seguranca-deploy/
└── projeto-final/
```
